Tulip & Honey Closet kawaii icon pack

These files contain images only. No website code is changed.

For GitHub Pages, upload the individual PNG and ICO files (not ZIP) to the same folder as index.html.

Because this is a GitHub Pages project website under /tulip-honey-closet/, adding icons alone may not make every browser discover them. If the icon does not show, explicit HTML <link rel="icon" href="./favicon.ico"> and <link rel="apple-touch-icon" href="./apple-touch-icon.png"> tags may be needed later.
